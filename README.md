==使用方法==  
・lottery_calculator.exeをダブルクリックまたは開くとcmd(ターミナル)で実行されると思います  
・選択肢が表示されたら使いたい計算機の番号を半角で入力してください  
・確率を入力するところには少数でも可能ですが単位は％として入力してください（％の入力は不要）  
・回数を入力するところについては整数で入力してください  
・計算が完了したあとにもう一度使用する場合はreと入力するともう一度使用できます  
・終了する場合は右上のバツ印をクリックしてタブを閉じてください
